# 缺陷報告 (Bug Reports)

本目錄收錄 Bug 軌 Step 1B（[bug-triage](../../.agents/skills/bug-triage/SKILL.md)）產出的缺陷報告。

* **命名**：`XXXX-<kebab-case>.md`，編號與 `docs/specs/` 共用同一流水號。
* **範本**：[bug_report_template.md](../templates/bug_report_template.md)
* **索引**：每份報告須登錄於 [docs/README.md](../README.md)「缺陷修正追溯清單」。
* **流程**：[bug.md](../../.agents/workflows/bug.md)（S2／S3）、[hotfix.md](../../.agents/workflows/hotfix.md)（S1）。
* **個資**：重現資料一律使用合成內容，不得貼入真實履歷片段或日誌中的個資。
